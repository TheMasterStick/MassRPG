# Authored World Placements

`MassRPG -> Placement Editor` writes exact anchored world placements here, paged independently from terrain.

Gameplay objects/resources keep a logical grid anchor while their 3D presentation may offset/rotate inside that anchor. Decorative doodads use the same persistence format but do not imply gameplay occupancy.

Normal deterministic biome dressing should **not** become a saved placement row for every tree or rock. This directory is for deliberate placements and local overrides: resource veins, rare trees, chests, workstations, NPC anchors, transport nodes, landmarks, manual doodads and similar authored exceptions.
