# Authored Semantic Areas

`MassRPG -> Area Editor` writes semantic area definitions here.

Areas are independent overlapping layers rather than partitions of the storage grid. Examples include named regions, biomes, level bands, faction territory, creature spawn regions, resource distribution zones, no-build footprints, forced-PvP areas and dungeon areas.

Each area has a stable content ID, explicit plane and either a circle or polygon shape. Player-map visibility is separate from simulation presence; creature/resource/system areas are normally not public map markers.
