# Authored Points of Interest

`MassRPG -> POI Editor` writes point-of-interest definitions here.

POIs cover capitals, towns, villages, settlements, dungeons, mines, ruins, shrines, docks, bridges, landmarks and transport points. Their public map category/visibility is independent from simulation data.

A POI's visible footprint and protected/no-build footprint are separate. Either can be omitted, use a quick circle, or use a hand-authored polygon. Service tags such as `service.bank` or `service.inn` support settlement-map filters without exposing every ordinary building or world object.
