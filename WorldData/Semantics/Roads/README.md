# Authored Roads

Road JSON files in this directory are written by `MassRPG -> Road Editor`.

Each road is a semantic polyline with stable ID, width, optional surface ground, player-map visibility and routing/spawn guidance. Roads are **not** fast-travel links and are not persisted as thousands of individual scene objects.

The rendered road surface, route-planner preference and future patrol/caravan behavior are derived from this semantic data.
